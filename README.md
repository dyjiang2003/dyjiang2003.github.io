# 个人主页

一个零依赖、零构建的静态个人主页。改内容不需要任何前端知识。

## 文件说明

| 文件 | 作用 | 需要修改吗 |
|---|---|---|
| `content.js` | 网页上的所有文字（姓名、介绍、作品、联系方式） | ✅ 改内容只改这个文件 |
| `life-content.js` | 生活页（life.html）上的所有文字：爱好、在读的书、在学的东西 | ✅ 改生活页只改这个文件 |
| `logos/` | 校徽 / 公司 logo 图片 | ✅ 要加 logo 就放这里 |
| `photos/` | 生活页卡片用的照片 | ✅ 要加照片就放这里 |
| `index.html` | 页面骨架 | ❌ 不用动 |
| `render.js` | 把 content.js 渲染成网页，并驱动星空/涟漪背景、换页特效和开关灯 | ❌ 不用动 |
| `life.html` / `life-render.js` | 生活页的骨架和渲染脚本 | ❌ 不用动 |
| `style.css` | 外观样式（颜色、字号、间距） | ❌ 一般不用动 |

## 怎么改内容

1. 用任意文本编辑器打开 `content.js`。
2. 文件里每个字段都有中文注释，照着占位符改即可。四条规则：
   - 文字放在英文双引号 `"..."` 里；
   - 每行末尾的英文逗号 `,` 别删；
   - 标注「可选」的行，不想要就整行删掉；
   - 想手动换行：在文字里写 `\n`（反斜杠+n）；写成 `[ ... ]` 列表的字段每一项自动各占一行/一段，不用写 `\n`。
3. 保存后刷新浏览器即可看到效果。

常见操作：

- **加一条作品**：复制 `works` 里任意一整段 `{ ... },`，粘贴后改文字。
- **加一段实习/科研经历**：复制 `experience` 里任意一整段 `{ ... },`，粘贴后改文字（按时间从新到旧排列）。
- **加一段自我介绍**：在 `intro` 的 `[ ]` 里加一行 `"新段落。",`。
- **加校徽/公司 logo**：把图片（png/jpg/svg 均可）放进 `logos/` 文件夹，然后在 `education` 或 `experience` 的对应条目里加一行 `logo: "文件名.png",`；也可以直接填完整网址。文件缺失时 logo 会自动隐藏，不影响文字显示。
- **改生活页内容**：打开 `life-content.js` 照注释改；想加卡片就复制某个 `{ ... },`，想加板块就复制整个 `{ heading: ..., items: [...] },`。
- **加生活页照片**：把照片（jpg/png）放进 `photos/` 文件夹，然后在 `life-content.js` 对应卡片里加一行 `photo: "文件名.jpg",`；没有 `photo` 的卡片自动是纯文字样式。
- **换 emoji**：从 <https://emojipedia.org> 复制图标替换。

## 怎么本地预览

- 方式一（最简单）：直接双击 `index.html`，浏览器打开即可。
- 方式二：在本目录运行 `python3 -m http.server 8000`，然后访问 <http://localhost:8000>。

## 怎么部署上线

本网站部署在 **GitHub Pages**，线上地址：`https://<你的GitHub用户名>.github.io/`。

**改完内容后让线上更新**，在本目录运行三行命令即可（约 1 分钟后生效）：

```bash
git add -A && git commit -m "update content" && git push
```
