# 个人主页

一个零依赖、零构建的静态个人主页。改内容不需要任何前端知识。

## 文件说明

| 文件 | 作用 | 需要修改吗 |
|---|---|---|
| `content.js` | 网页上的所有文字（姓名、介绍、作品、联系方式） | ✅ 改内容只改这个文件 |
| `index.html` | 页面骨架 | ❌ 不用动 |
| `render.js` | 把 content.js 渲染成网页 | ❌ 不用动 |
| `style.css` | 外观样式（颜色、字号、间距） | ❌ 一般不用动 |

## 怎么改内容

1. 用任意文本编辑器打开 `content.js`。
2. 文件里每个字段都有中文注释，照着占位符改即可。三条规则：
   - 文字放在英文双引号 `"..."` 里；
   - 每行末尾的英文逗号 `,` 别删；
   - 标注「可选」的行，不想要就整行删掉。
3. 保存后刷新浏览器即可看到效果。

常见操作：

- **加一条作品**：复制 `works` 里任意一整段 `{ ... },`，粘贴后改文字。
- **加一段自我介绍**：在 `intro` 的 `[ ]` 里加一行 `"新段落。",`。
- **换 emoji**：从 <https://emojipedia.org> 复制图标替换。

## 怎么本地预览

- 方式一（最简单）：直接双击 `index.html`，浏览器打开即可。
- 方式二：在本目录运行 `python3 -m http.server 8000`，然后访问 <http://localhost:8000>。

## 怎么部署上线

- **GitHub Pages**：把整个目录推到 GitHub 仓库 → 仓库 Settings → Pages → 选择分支根目录，几分钟后通过 `https://<用户名>.github.io/<仓库名>/` 访问。
- **Vercel / Netlify**：登录后把这个文件夹拖进去即可，会自动分配域名。
- **自己的服务器**：把 4 个文件上传到 Nginx 的网站根目录（如 `/var/www/html/`）。

绑定个人域名参考各托管平台的 "Custom domain" 文档。
